KU admission demand pipeline

Questions
Which Kasetsart University bachelor's programmes do the most applicants compete for, how many seats do they have, and what score does each one need?
What I built
An Airflow DAG that combines TCAS statistics from mytcas.com, new-student data from the data.go.th API, and seats scraped from admission.ku.ac.th into PostgreSQL (1,917 rows across 264 programmes). If a source is down, the run still finishes and is flagged as partial on a pipeline status page.
Built with
Python, Apache Airflow, PostgreSQL, Docker, requests and BeautifulSoup, Streamlit.
